# TaskDesk

TaskDesk is a simple Java-based ticket management application built as part of my Java learning journey.

## Features

- Create new tickets
- View all tickets
- Assign tickets to agents
- Change ticket status
- Add comments to tickets
- Filter tickets using lambda expressions

## Technologies Used

- Java 25
- IntelliJ IDEA

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/roshna-dev/taskdesk
   ```

2. Open the project in IntelliJ IDEA.
3. Set the Project SDK to Java 25.
4. Locate `Main.java` inside `src/com/taskdesk/model/`.
5. Right-click `Main.java` and select **Run 'Main.main()'**.

## Note

This version stores all ticket data in memory. Data will reset when the application is restarted.
